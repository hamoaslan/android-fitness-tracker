# Android Fitness Tracker
​
Android Fitness Tracker is a fitness application developed as a university team project. The app combines several tools for recording and evaluating fitness and health-related activities.
​
## Features
​
- Step counting and activity statistics
- GPS-based running tracker with OpenStreetMap
- Storage and display of recorded running routes
- Telemetry such as speed and elapsed time
- Sensor-based workout and repetition tracking
- Nutrition tracking with barcode scanning
- Live data sharing and multiplayer workouts
​
## Technologies
​
The application was developed with **Java**, **Kotlin**, and the **Android SDK**. It uses **Room** for local data storage, **OpenStreetMap** for route visualization, **Retrofit** for API communication, and **MQTT** for real-time data exchange.
​
## Project Context
​
This application was created as a university team project. It demonstrates the use of Android sensors, GPS tracking, local databases, external APIs, maps, and communication between multiple devices.
​
The project was developed for educational purposes.
